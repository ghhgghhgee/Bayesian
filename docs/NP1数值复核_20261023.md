# NP1 数值差异复核与修复

## 问题来源和结论

基于主分支 `09b125cd3f9d26aeaf88e8b97211b068dacc2dfe`，复核
`docs/组长前三项验收_20261021.md` 和
`results/leader_20261021_reference_differences.json`。
组长指出的不是接口运行失败：旧模块已通过运行和重复性检查，但在
M=10、K=3 的零起始编号 trial 52、135、161 上，恢复成功判定与参考不同，
困难工况最终估计的差异较大，需由作者解释。

本机重现了上述三个样本、各工况成功数及最大估计差。
原因是同一伪逆公式的浮点求值路径不同；不是漏掉后验方差项、a/b 更新顺序颠倒，
也不是读取了真值。此次统一后验计算顺序，消除这批测试数据上成员与参考的差异。
这不证明参考实现是论文作者原版代码，也不意味着恢复性能提高。

## 数学与数值路径

令 `D=diag(sqrt(v))`、`B=A diag(other_mean) D`，论文式 (10)–(13) 为：

```text
mean = D B^+ y
Cov  = D (I - B^+ B) D
diag(Cov) = v * (1 - diag(B^+ B))
```

保留的奇异值对应 `B^+=V_r diag(1/s_r) U_r.T`。
旧实现将均值结合为 `V_r @ ((U_r.T @ y)/s_r)`，并将
`diag(B^+ B)` 化简为 `sum(V_r**2, axis=1)`。
这些在精确算术下等价，但浮点舍入不同；NP1 的交替更新会在敏感样本上放大扰动。
三个问题样本的第一次 a 更新中，均值最大差约为 `7e-18` 至 `1.4e-17`，
方差最大差约为 `2.2e-16` 至 `4.4e-16`。

修复在 `NP1.py::_posterior` 中完成：

1. 保留一次薄 SVD 和原有相对奇异值截断规则。
2. 按 NumPy `pinv` 的乘法顺序显式构造 `B^+`，随后计算 `B^+ @ y`。
3. 用 `einsum("ij,ji->i", inverse, B)` 计算投影矩阵的对角线，
   与参考相同仅将负的后验方差截为零。
4. 截断奇异值的倒数直接置零，零矩阵不会发生除零。

仍不构造 N×N 协方差矩阵，但新增 N×M 伪逆中间数组；每轮仍为两次薄 SVD。
初始化、完整二阶矩更新、停止准则及默认阈值均保持原约定。
`main.py`、`bcs/algorithms.py`、注册表和其他成员算法无需修改。
框架仍通过 `NP1:solve` 调用成员入口；真值仅由评估器使用。

## 本机修复前后对照

配置与组长一致：N=100、seed=20261019，标准正态 A 和非零幅度，
不做列归一化，无噪声，三个工况每个 300 个独立样本。
最多 300 次迭代，tol=1e-3、rcond=1e-12、variance_floor=1e-30；
成功为相对误差严格小于 1e-3。

| M | K | 旧成员成功数 | 修复后成功数 | 参考成功数 | 旧版与参考最大逐坐标差 | 修复后差 |
|---:|---:|---:|---:|---:|---:|---:|
| 10 | 3 | 226/300 | 225/300 | 225/300 | 0.5860865895 | 0 |
| 30 | 3 | 300/300 | 300/300 | 300/300 | 8.4672e-15 | 0 |
| 30 | 15 | 98/300 | 98/300 | 98/300 | 0.3471316905 | 0 |

900 个样本上修复后与参考的完整轨迹和停止状态也一致。
这是当前固定环境及数据的实测结果，不承诺所有平台、输入或参数逐位一致。
独立入口 `solve_np1` 仍有不同的默认阈值；本模块停止分母为真实范数，
参考为 `max(norm,1e-30)`，极小量级输入仍可能有不同停止行为。
成功率从 226/300 变为 225/300 是统一数值路径的结果，不应包装成性能提升。

证据：`results/np1_fix_20261023_before_after.json`，包含源码 SHA256、数据指纹、
三个问题样本的误差和迭代数，以及其他工况的汇总。
运行环境为 Windows、Python 3.11.5、NumPy 2.2.4、SciPy 1.15.2，
BLAS 线程数固定为 1；组长此前为 Python 3.12.14。

## 测试与复跑

新增 `tests/test_np1_numerics.py`：三个问题样本的轨迹回归、零及截断奇异值检查。
回归测试在旧代码上确实失败，修复后通过。另将成员独立项目的 15 项测试纳入仓库
`tests/test_np1_formulas.py`，其中公式参考显式构造完整矩阵，核对一次、多次、
秩亏情况下的均值、协方差、精度更新；其余覆盖边界、恢复、停止及输入保护。
仓库共 51 项测试通过，日志见 `results/np1_fix_20261023_tests.txt`。

在仓库根目录执行；输出目录应使用未占用的名称：

```powershell
python -m unittest discover -s tests -v
python main.py run --config configs/np1_validation.json --out results/np1_fix_20261023_a --data-dir data/np1_fix_20261023_a
python main.py run --config configs/np1_validation.json --out results/np1_fix_20261023_b --data-dir data/np1_fix_20261023_b
python main.py compare results/np1_fix_20261023_a results/np1_fix_20261023_b --report results/np1_fix_20261023_reproducibility.json
python scripts/audit_np0_outputs.py results/np1_fix_20261023_a results/np1_fix_20261023_b --out results/np1_fix_20261023_numerical_audit.json
```

两轮之间不要更改源码或配置。每轮 1,800 次调用，两轮 3,600 次；
仍为同样的 900 个独立样本。最后一条沿用组长通用审计脚本，虽名为 NP0，
也会逐条检查 NP1 的估计、轨迹、时间、停止条件及独立重算指标。
两轮结果和审计结论另见 `results/np1_fix_20261023验收.md`。

修复前后诊断可另行复跑：从上述基准提交取出旧 `NP1.py` 保存为
`tmp/NP1_before.py`，再执行：

```powershell
python scripts/audit_np1_numerics.py --before tmp/NP1_before.py --out results/np1_before_after_repeat.json
```
