## 一条命令重新生成

在仓库根目录、安装 requirements.txt 的 Python 环境运行：

```powershell
python scripts/review_np1_cases.py --out results/np1_review_mine
```

输出目录须为新的空目录。不需要下载历史数据，也不需要原来的大体积 histories.npz。脚本会重新生成三个输入，实际调用注册表中的 NP1 和 NP1_MEMBER；不会修改核心算法。

本机已有输出在 `results/np1_review_20261022/`。本机还用 `--historical-run results/leader_20261021_np1_a` 核对了新运行与昨日保存的估计；普通克隆不含历史大文件，省略该参数即可。

已经验证省略历史参数的独立运行：全部导出输入、估计和轨迹与本机案例包一致；另独立核对 y=A x、MSE、成功判定、末步估计及输出哈希。验证结果保存在 results/preparation_20261022_checks.json。

## 看哪些文件

| 文件 | 内容 |
|---|---|
| summary.csv | 每个样本、每种实现的相对误差、MSE、成功判定、迭代数、测量残差 |
| coordinates.csv | 三个样本各 100 个坐标的真值、参考估计、成员估计及两种估计之差 |

| cases.npz | A、y、真实 x、两种估计和完整迭代向量；小型案例包纳入 Git |
