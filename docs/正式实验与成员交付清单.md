快速检查（先安装 requirements.txt；输出名称换成未使用过的名称）：

```powershell
python main.py run --config configs/paper_members_smoke.json --out results/team_smoke_a
python main.py run --config configs/paper_members_smoke.json --out results/team_smoke_b
python main.py compare results/team_smoke_a results/team_smoke_b --report results/team_smoke_compare.json
python main.py plot results/team_smoke_a
```

基线与核心版本确认后，实验同学再运行完整配置：

```powershell
python main.py run --config configs/paper_members.json --out results/paper_members_a
python main.py plot results/paper_members_a
```

组长在同一源码版本独立复跑到新的目录，再执行 compare。两次 run 之间不要修改源码、配置或文档；登记源码哈希会随这些文件变化。改变算法版本或参数时须重新建立整对实验，不能混用旧结果。
